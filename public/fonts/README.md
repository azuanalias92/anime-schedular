# Orbitron

`orbitron-latin-variable.woff2` is the unmodified Latin variable font (weights 400–900) served by Google Fonts for Orbitron.

- Specimen: https://fonts.google.com/specimen/Orbitron
- Download: https://fonts.gstatic.com/s/orbitron/v35/yMJRMIlzdpvBhQQL_Qq7dy0.woff2
- License: SIL Open Font License 1.1; see `OFL.txt`.

The app serves this font locally and precaches it for offline use. Characters outside the font's coverage use the configured system fallback.
